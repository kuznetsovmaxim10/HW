# Домашнее задание 3 - Сбор данных о книгах

Проект собирает информацию о книгах с сайта [Books to Scrape](https://books.toscrape.com/), сохраняет результат в текстовый файл и поддерживает ежедневную выгрузку.

Основные функции находятся в `scraper.py`. Ноутбук `notebooks/HW_03_python_ds.ipynb` содержит выполнение домашнего задания и выводы ячеек.

## Структура проекта

## Установка

Требуется Python 3.10 или новее. Откройте терминал в папке `books_scraper` и установите зависимости в выбранное окружение:

```bash
python -m pip install -r requirements.txt
```

Основные библиотеки:

- `requests`;
- `beautifulsoup4`;
- `schedule`;
- `pytest`.

Для работы с ноутбуком также необходим редактор с поддержкой Jupyter, например VS Code.
Выберите в ноутбуке окружение, в котором установлены зависимости.

## Сбор данных

`get_book_data(book_url)` возвращает словарь: название, рейтинг, количество в наличии, описание, UPC, тип продукта, цену без налога, цену с налогом, налог и количество отзывов.

Пример вызова из Python при рабочей папке `books_scraper`:

```python
from scraper import scrape_books

res = scrape_books(is_save=True)
print(type(res), len(res))
```

Для сбора первых трёх страниц:

```python
res = scrape_books(is_save=True, n=3)
```

Если `n` не указан, обход продолжается до конца каталога. Если `n` превышает число страниц, сбор останавливается на последней странице. Допустимы положительное целое число или `None`.

Путь сохранения - `artifacts/books_data.txt`. При `is_save=True` файл создаётся или полностью перезаписывается результатом текущего сбора, включая сбор с ограничением `n`. Формат данных — JSON, кодировка — UTF-8. При `is_save=False` файл не создаётся и не изменяется.

Полный сбор требует доступа к сайту и может занять несколько минут. Данные записываются после завершения обхода.


## Ежедневная выгрузка

Функция `run_scheduler("19:00")` запускает ежедневный сбор с сохранением. Время соответствует локальному часовому поясу компьютера.

Планировщик работает в основном потоке. Для остановки в терминале нажмите Ctrl+C. При вызове в ноутбуке ячейка занимает ядро до остановки через Interrupt Kernel; остальные ячейки ожидают выполнения.

## Автотесты

Тесты размещаются в `tests/test_scraper.py`.

Проверяются:

- поля книги и отсутствие вложенности и дублей;
- переход между страницами и работа без сохранения;
- сохранение результата в файл.

Тесты с локальными HTML-примерами подменяют HTTP-запросы и не требуют доступа к сайту. Для проверки сохранения используется временная папка, поэтому реальный файл с данными не перезаписывается.

Запуск из корня проекта в терминале:

```bash
python -m pytest tests/test_scraper.py -v
```

Также реализован запуск тестов одной ячейкой ноутбука.
